Introduction to Logarithmic and Exponential Functions

A review of the fundamental properties and calculus rules for logarithmic and exponential functions.

Exponential and Logarithmic Functions are inverses of each other. They satisfy:

$$f(f^{-1}(x))=f^{-1}(f(x))=x$$

Which means:

$$\log_{a} (a^{x}) = a^{\log_{a}(x)}=x$$

as long as the base $a$ remains constant throughout.

Change of Base Formula

To change a logarithm of $x$ in base $a$ to base $b$:

$$\log_{a}x=\frac{\log_{b}x}{\log_{b}a}$$
Key Concepts from Previous Course
  • The derivative of $y=e^x$ is $e^x$ (Natural Exponential Function)
  • The derivative of $y=a^x$ is $a^x \ln a$
  • The derivative of $y=\ln x$ is $\frac{1}{x}$
  • The derivative of $y=\log_{a} x$ is $\frac{1}{x \ln a}$
  • Integration often requires substitution
Summary of Derivatives
$$\begin{aligned} & \frac{d}{dx}\left(e^{u(x)}\right)=e^{u(x)}\times \frac{du}{dx}\\ &\frac{d}{dx}\left( a^{u(x)}\right) = a^{u(x)}\ln a\times\frac{du}{dx} \\ & \frac{d}{dx}\left( \ln u(x)\right) = \frac{1}{u(x)}\times \frac{du}{dx}\\ &\frac{d}{dx}\left( \log_{a}u(x)\right)=\frac{1}{u(x)\ln a}\times\frac{du}{dx} \end{aligned}$$
Summary of Integrals
$$\begin{aligned} &\int e^{u(x)} \, du=e^u+c\\ &\int a^{u(x)} \, du=\frac{a^{u(x)}}{\ln a}+c\\ &\int \frac{1}{u(x)}\, du = \ln |u(x)|+c \end{aligned}$$

Logarithmic Differentiation

The technique of logarithmic differentiation simplifies complex functions by using logarithms to transform products, quotients, and exponents into simpler expressions.

Example: Complex Function

Differentiate $y=\frac{x^5}{(1-10x)\sqrt{x^2+2}}$

Solution:

Apply natural logarithms to both sides:

\[\ln y = \ln \left(\frac{x^5}{(1-10x)\sqrt{x^2+2}} \right)\]

Simplify using logarithm properties:

\[\ln y = \ln x^5 - \ln(1-10x) - \frac{1}{2}\ln (x^2+2)\]

Differentiate implicitly:

\[\frac{1}{y} \frac{dy}{dx} = \frac{5}{x} + \frac{10}{1-10x} - \frac{x}{x^2 + 2}\]

Solve for $\frac{dy}{dx}$:

\[\frac{dy}{dx} = y \left( \frac{5}{x} + \frac{10}{1-10x} - \frac{x}{x^2 + 2} \right)\]

Substitute back for $y$:

\[\frac{dy}{dx} = \frac{x^5}{(1-10x)\sqrt{x^2+2}} \left( \frac{5}{x} + \frac{10}{1-10x} - \frac{x}{x^2 + 2} \right)\]
Example: Exponential Function

Differentiate $y=x^x$

Solution:

\[\ln y = x \ln x\] \[\frac{1}{y} \frac{dy}{dx} = \ln x + 1\] \[\frac{dy}{dx} = x^x (\ln x + 1)\]
Example: Trigonometric Exponent

Differentiate $y=(1-3x)^{\cos x}$

Solution:

\[\ln y = \cos x \ln(1-3x)\] \[\frac{1}{y} \frac{dy}{dx} = -\sin x \ln(1-3x) - \frac{3 \cos x}{1-3x}\] \[\frac{dy}{dx} = -(1-3x)^{\cos x} \left[ \sin x \ln(1-3x) + \frac{3 \cos x}{1-3x} \right]\]
Basic Differentiation Formulas
$\frac{d}{dx}(c)=0$ Constant Differentiation
$\frac{d}{dx}(x^n)=nx^{n-1}$ Power Rule
$\frac{d}{dx}(a^x)=a^x\ln a$ Exponential Function
$\frac{d}{dx}(x^x)=x^x(1+\ln x)$ Logarithmic Differentiation

Logarithmic Integration

Understanding how to use logarithms in integration problems.

Important Integral
\[\int \frac{1}{u} \, du = \ln |u| + C\]

This result comes from the derivative of $\ln x$ and cannot be solved using the power rule.

Example: Basic Integral

Evaluate $\int\limits_1^e \frac{1}{x} \, dx$

Solution:

\[\int\limits_1^e \frac{1}{x}\, dx = [\ln x]_1^e = \ln e - \ln 1 = 1 - 0 = 1\]
Example: Substitution Method

Evaluate $\int \frac{3x^2}{x^3 +5}\, dx$

Solution:

Let $u = x^3 + 5$, then $du = 3x^2 dx$

\[\int \frac{3x^2}{x^3 +5}\, dx = \int \frac{1}{u} du = \ln |u| + C = \ln |x^3+5| + C\]
Example: Trigonometric Integral

Evaluate $\int \tan x \, dx$

Solution:

\[\int \tan x \, dx = \int \frac{\sin x}{\cos x} dx\]

Let $u = \cos x$, $du = -\sin x \, dx$

\[\int \frac{\sin x}{\cos x} dx = -\int \frac{du}{u} = -\ln |u| + C = -\ln |\cos x| + C\]
Example: Nested Logarithm

Evaluate $\int \frac{dx}{x\ln x}$

Solution:

Let $u = \ln x$, $du = \frac{1}{x} dx$

\[\int \frac{dx}{x\ln x} = \int \frac{du}{u} = \ln |u| + C = \ln |\ln x| + C\]

Inverse Trigonometric Functions

Understanding the derivatives of inverse trigonometric functions and their applications.

Derivative of $\arcsin x$

Let $y = \arcsin x$, then $x = \sin y$

\[\frac{dy}{dx} = \frac{1}{\cos y} = \frac{1}{\sqrt{1 - x^2}}\]

Thus:

\[\frac{d}{dx}(\arcsin x) = \frac{1}{\sqrt{1 - x^2}}\]
Derivative of $\arccos x$

Let $y = \arccos x$, then $x = \cos y$

\[\frac{dy}{dx} = -\frac{1}{\sin y} = -\frac{1}{\sqrt{1 - x^2}}\]

Thus:

\[\frac{d}{dx}(\arccos x) = -\frac{1}{\sqrt{1 - x^2}}\]
Derivative of $\arctan x$

Let $y = \arctan x$, then $x = \tan y$

\[\frac{dy}{dx} = \frac{1}{\sec^2 y} = \frac{1}{1 + x^2}\]

Thus:

\[\frac{d}{dx}(\arctan x) = \frac{1}{1 + x^2}\]
Summary of Inverse Trig Derivatives
$$\begin{aligned} &\frac{d}{dx}(\sin^{-1} u) = \frac{1}{\sqrt{1 - u^2}} \cdot \frac{du}{dx} \\ &\frac{d}{dx}(\cos^{-1} u) = -\frac{1}{\sqrt{1 - u^2}} \cdot \frac{du}{dx} \\ &\frac{d}{dx}(\tan^{-1} u) = \frac{1}{1 + u^2} \cdot \frac{du}{dx} \\ &\frac{d}{dx}(\cot^{-1} u) = -\frac{1}{1 + u^2} \cdot \frac{du}{dx} \\ &\frac{d}{dx}(\sec^{-1} u) = \frac{1}{|u|\sqrt{u^2 - 1}} \cdot \frac{du}{dx} \\ &\frac{d}{dx}(\csc^{-1} u) = -\frac{1}{|u|\sqrt{u^2 - 1}} \cdot \frac{du}{dx} \end{aligned}$$
Example: Composite Function

Differentiate $y = \sin^{-1}(x^3)$

Solution:

\[\frac{dy}{dx} = \frac{1}{\sqrt{1 - (x^3)^2}} \cdot 3x^2 = \frac{3x^2}{\sqrt{1 - x^6}}\]

Integrals Involving Inverse Trig Functions

Using the derivatives of inverse trig functions to find their integrals.

Key Inverse Trig Integrals
$$\begin{aligned} &\int \frac{1}{\sqrt{1 - u^2}} \, du = \sin^{-1} u + C \\ &\int \frac{1}{1 + u^2} \, du = \tan^{-1} u + C \\ &\int \frac{1}{|u|\sqrt{u^2 - 1}} \, du = \sec^{-1} |u| + C \end{aligned}$$
Example: Exponential Integral

Evaluate $\int \frac{e^x}{\sqrt{1 - e^{2x}}} \, dx$

Solution:

Let $u = e^x$, $du = e^x dx$

\[\int \frac{e^x}{\sqrt{1 - e^{2x}}} dx = \int \frac{1}{\sqrt{1 - u^2}} du = \sin^{-1}(u) + C = \sin^{-1}(e^x) + C\]
Example: Quadratic Denominator

Evaluate $\int \frac{1}{1 + 3x^2} \, dx$

Solution:

Let $u = \sqrt{3}x$, $dx = \frac{du}{\sqrt{3}}$

\[\int \frac{1}{1 + 3x^2} dx = \frac{1}{\sqrt{3}} \int \frac{1}{1 + u^2} du = \frac{1}{\sqrt{3}} \tan^{-1}(u) + C = \frac{1}{\sqrt{3}} \tan^{-1}(\sqrt{3}x) + C\]
General Integrals
$$\begin{aligned} &\int \frac{du}{\sqrt{a^2 - u^2}} = \sin^{-1} \left(\frac{u}{a} \right) + C \\ &\int \frac{du}{a^2 + u^2} = \frac{1}{a} \tan^{-1} \left( \frac{u}{a} \right) + C \\ &\int \frac{du}{u \sqrt{u^2 - a^2}} = \frac{1}{a} \sec^{-1} \left| \frac{u}{a} \right| + C \end{aligned}$$
Example: Square Root Denominator

Evaluate $\int \frac{dx}{\sqrt{9 - x^2}}$

Solution:

\[\int \frac{dx}{\sqrt{9 - x^2}} = \sin^{-1} \left( \frac{x}{3} \right) + C\]
